# ForecastInfluence implementation handoff

ForecastInfluence is a working Python library measuring how historical training
evidence affects forecasts, realized squared error or coefficients. Every query
declares its source, intervention, target and computation method. Local version:
**0.1.0.dev0**. Author: **Malek Itani**. License: **MIT**.

## Implemented work

1. Validated indexed univariate data and strict rolling/expanding windows.
2. Lag features with original-value provenance and horizon-specific case IDs.
3. OLS/ridge with fixed baseline normalization and unpenalized intercepts.
4. Direct/recursive forecasting and recursive parameter sensitivities.
5. Independent/grouped case weights and consistent raw additions/replacements.
6. Implicit case derivatives, central differences and finite reference refits.
7. Forecast, full squared-error and separate parameter targets.
8. Rolling masks, resource budgets, sequential batches and failure records.
9. Labeled results, explicit ranking/aggregation, comparisons and safe exports.
10. Four plots, eight examples, synthetic scenarios and experiment runner.
11. Independent tests, CI and clean-install package checks.
12. README, guides, generated API docs, research register, MIT/CFF metadata.

## Repository and architecture

```text
src/forecastinfluence/
  core.py, capabilities.py           shared contracts and failures
  data.py, features.py, synthetic.py observations, provenance and generators
  models.py                         native objective solvers and snapshots
  forecasting.py                    forecast strategies and chain rule
  interventions.py, targets.py       typed scientific requests

  results.py, serialization.py       labeled schemas and safe persistence
  diagnostics.py, plotting.py        comparisons and optional figures
  experiments/                      TOML schema, runner and CLI
tests/                              numerical/temporal/property/adapter gates
examples/                           eight standalone offline scripts
benchmarks/configs/smoke.toml        reproducible small study
scripts/                            README sync, figure and release checks
docs/                               site, research, decisions and evidence
.github/workflows/ci.yml             configured verification matrix
dist/                               local wheel and source archive
```

The facade coordinates components; fitting, lag building, plotting and export
live separately. Base imports do not load optional plotting or experiments.
The supplied specification files are preserved at the root.

## Installation and commands

From this checkout in Python 3.11+ (3.12 locally verified):

```sh
python -m pip install -e ".[dev,docs,plots]"
python examples/quickstart.py
python scripts/check_readme_examples.py --run
python -m pytest --cov=forecastinfluence --cov-branch
python -m ruff check .
python -m ruff format --check .
python -m mypy src/forecastinfluence
python -m forecastinfluence.experiments.cli run --config benchmarks/configs/smoke.toml --output artifacts/new-run
python scripts/generate_example_assets.py
python -m mkdocs build --strict
python -m mkdocs serve
python -m build
python -m twine check dist/*
python scripts/check_release.py
```

On this workstation use `.venv\Scripts\python.exe` for `python`; the environment
is already installed. Choose a new experiment directory for each run. Versions
are recorded in `requirements-tested-windows-py312.txt`; documentation tool pins
are in `requirements-docs.txt`.

## Assumptions and limitations

Finite effects are after minus before. Derivatives are per absolute weight or
original data unit. Removing a case does not remove a raw observation. The toy
mean [1,2,4] has derivative 5/9 and finite deletion effect -5/6. Full realized
squared-error targets differ from the half-squared training objective.

OLS requires numerical uniqueness; ridge needs positive training weight. No
hidden inverse fallback, damping, scaling, imputation or tuning is applied.
Datetime grids are timezone-naive and fixed. Default replay freezes identity
preprocessing, hyperparameters, n0 and truth, and rebuilds context. Fixed context
is explicit. Baseline fitting errors stop the study; intervention numerical
failures may be recorded as NaN/status. Budgets cover result arrays and fit counts,
not process RAM or execution time. Large effects are not proof of data errors,
forecast harm or causality. Numeric diagnostics are not confidence intervals.

The [related work](../research/related-work.md) and
[claims register](../research/novelty-claims.md) acknowledge established methods;
no priority, novelty or superiority claim is made.
